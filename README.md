# โหวตไทย

**เสียงของคุณ นับทุกเสียง และตรวจสอบได้ว่านับจริง**

โหวตไทยคือระบบโหวตและรับฟังความเห็นออนไลน์ ผู้ใช้ยืนยันตัวตนด้วย ThaiID ผู้ดูแลสร้างแบบโหวตและกำหนดวันเริ่มวันสิ้นสุด ทุกคนโหวตได้หนึ่งเสียงต่อหนึ่งหัวข้อ

## ทำไมต้องมี

การโหวตออนไลน์ส่วนใหญ่ขอให้ผู้โหวตเชื่อใจผู้จัด ว่าไม่มีใครโหวตซ้ำ ไม่มีใครแอบแก้ตัวเลข และไม่มีใครรู้ว่าใครเลือกอะไร แต่ผู้โหวตแทบไม่มีทางตรวจสอบเองได้

เราคิดกลับกัน **ระบบที่น่าเชื่อถือไม่ควรต้องขอให้ใครเชื่อใจ** กติกาสำคัญถูกฝังไว้ในระบบ ไม่ใช่แค่คำสัญญา ใครก็ตรวจได้ รวมถึงผู้ดูแลเอง

## หลักการ 6 ข้อ

### 1. หนึ่งคน หนึ่งเสียง
ทุกคนยืนยันตัวตนก่อนโหวต และโหวตได้ครั้งเดียวต่อหนึ่งหัวข้อ กติกานี้บังคับที่ระดับฐานข้อมูล ต่อให้กดซ้ำพร้อมกันหรือเปิดหลายหน้าต่าง ระบบก็รับแค่ใบเดียว

### 2. คะแนนเป็นความลับ เมื่อหัวข้อต้องการ
ผู้ดูแลเลือกได้ทุกหัวข้อ
- **ไม่ระบุตัวตน** ระบบรู้แค่ว่าคุณโหวตแล้ว แต่ไม่ผูกชื่อคุณกับตัวเลือกที่เลือก
- **เปิดเผยชื่อ** เหมาะกับการลงมติที่ต้องรับผิดชอบต่อสาธารณะ ทุกคนเห็นว่าใครเลือกอะไร

ผู้โหวตเห็นก่อนโหวตเสมอว่าหัวข้อนี้เป็นแบบไหน

### 3. ตรวจสอบเสียงของตัวเองได้
หลังโหวต คุณจะได้รหัสใบรับรองหนึ่งชุด นำไปตรวจทีหลังได้ว่าเสียงของคุณอยู่ในระบบจริง ระบบจะไม่บอกว่าคุณเลือกอะไร จึงไม่มีใครใช้ใบรับรองไปพิสูจน์คะแนนให้คนที่มาซื้อเสียงได้

### 4. กติกาไม่เปลี่ยนกลางทาง
เมื่อแบบโหวตเริ่มแล้ว ผู้ดูแลแก้หัวข้อ ตัวเลือก หรือเวลาไม่ได้ ปิดก่อนกำหนดได้ แต่เปิดใหม่ไม่ได้ ใบโหวตที่บันทึกแล้วแก้หรือลบไม่ได้ ระบบเปิดและปิดโหวตตามเวลาที่ประกาศไว้ ไม่ต้องรอใครกดปุ่ม

### 5. ถ้ามีการแก้ผลลับหลัง ต้องมีร่องรอย
ใบโหวตทุกใบถูกผูกต่อกันเป็นลูกโซ่ ถ้ามีใครแก้ ลบ หรือแทรกใบโหวต ลูกโซ่จะขาด และระบบตรวจพบได้ทันทีเมื่อกดตรวจสอบ นอกจากนี้ทุกการกระทำของผู้ดูแลถูกจดไว้ในบันทึกที่แก้ไขไม่ได้จากหน้าเว็บ

### 6. เก็บข้อมูลเท่าที่จำเป็น
ระบบไม่เก็บเลขบัตรประชาชนจริง เก็บเพียงค่าที่แปลงแล้วซึ่งใช้ยืนยันว่าเป็นคนเดิม ย้อนกลับเป็นเลขบัตรไม่ได้ ผู้ดูแลระบบและผู้โหวตแยกกันคนละส่วนโดยสิ้นเชิง

## ใช้งานง่าย

**สำหรับผู้โหวต**
1. เข้าสู่ระบบด้วย ThaiID
2. เลือกหัวข้อที่เปิดอยู่ ตอบ แล้วตรวจทานก่อนกดยืนยัน
3. รับรหัสใบรับรอง และดูผลตามที่ผู้ดูแลกำหนด

**สำหรับผู้ดูแล**
1. สร้างแบบโหวต เลือกรูปแบบ ตั้งวันเริ่มและวันสิ้นสุด
2. เผยแพร่ ระบบเปิดและปิดโหวตให้เอง
3. ดูผล ตรวจความถูกต้อง และดูแลความเห็น

**รูปแบบที่รองรับ**
- เลือก 1 ข้อ
- เลือกได้หลายข้อ โดยกำหนดจำนวนสูงสุด
- เห็นด้วย / ไม่เห็นด้วย / งดออกเสียง
- แสดงความเห็นเป็นข้อความ

ผู้ดูแลเลือกได้ด้วยว่าจะ **แสดงผลสด** หรือ **แสดงเมื่อปิดโหวต** แบบหลังช่วยไม่ให้ผลที่เห็นอยู่ชักนำคนที่ยังไม่ได้โหวต

หน้าเว็บเป็นภาษาไทย ธีมสว่าง เรียบง่าย ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ

## เหมาะกับ

- สภานักเรียนและสโมสรนักศึกษา
- ชุมชน หมู่บ้าน และนิติบุคคลอาคารชุด
- สหกรณ์ สมาคม และองค์กรที่ต้องลงมติสมาชิก
- การรับฟังความเห็นจากประชาชนของหน่วยงานท้องถิ่น
- ทีมและบริษัทที่อยากได้ผลโหวตที่เชื่อถือได้

## ตรงไปตรงมาเรื่องข้อจำกัด

ความน่าเชื่อถือมาจากการบอกว่าทำอะไรได้และยังทำไม่ได้
- **ThaiID ยังเป็นโหมดจำลอง** ตอนนี้เลือกตัวตนใดก็ได้เพื่อทดลองใช้ ระบบออกแบบให้เปลี่ยนเป็น ThaiID จริงได้โดยไม่ต้องแก้ส่วนอื่น แต่ยังไม่ควรใช้ลงมติจริงจนกว่าจะเชื่อมต่อเสร็จ
- **ผู้ที่เข้าถึงฐานข้อมูลโดยตรงมีอำนาจมากกว่าที่แอปควบคุมได้** ระบบจะตรวจจับการแก้ไขได้ ถ้ามีการจดค่ายืนยันผลไว้ภายนอกเมื่อปิดโหวต
- **ออกแบบสำหรับกลุ่มขนาดชุมชนถึงองค์กร** ไม่ใช่การเลือกตั้งระดับประเทศ
- **ยังไม่มีรายชื่อผู้มีสิทธิ์ต่อหัวข้อ** ผู้ที่ยืนยันตัวตนได้ทุกคนโหวตได้ทุกหัวข้อ
